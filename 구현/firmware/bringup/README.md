# 단계별 확인 스케치

**한 번에 다 꽂고 돌리지 않는다.** 안 될 때 어디가 문제인지 알 수 없기 때문이다.
아래 순서대로 하나씩 통과시킨다. 각 단계는 앞 단계가 통과했다는 걸 전제한다.

| | 스케치 | 확인하는 것 | 통과 기준 |
|---|---|---|---|
| W1 | `01_i2c_scan` | 보드가 살아 있고 I2C에 두 장치가 보인다 | `0x3C` `0x68` 두 주소가 뜬다 |
| W1 | `02_oled_hello` | OLED 라이브러리·주소 설정 | 화면에 글자가 보인다 |
| W2 | `03_mpu_rate` | **MPU의 실제 출력 속도**와 정지 magnitude | 오차 ±1%, magnitude 1.00±0.05 g |

Arduino IDE는 폴더명과 `.ino` 파일명이 같아야 연다. 폴더째로 여세요.

## 배선 — 한 번에 다 하지 않는다

```
1단계 (01 스케치용)
  ESP32 3V3 ──┬── MPU VCC
              └── OLED VCC
  ESP32 GND ──┬── MPU GND
              └── OLED GND
  GPIO21 ─────┬── MPU SDA ── OLED SDA
  GPIO22 ─────┴── MPU SCL ── OLED SCL

3단계 (부저·스위치는 W4 전까지 안 꽂아도 된다)
  GPIO25 ──────── 부저(+)       부저(−) → GND
  GPIO14 ──────── 스위치 한쪽    스위치 다른쪽 → GND
```

· **VCC는 3V3에 꽂는다. VIN(5V) 아니다.** GY-521 모듈은 5 V도 받지만,
  ESP32의 I/O가 3.3 V라 3V3으로 통일하는 쪽이 안전하다
· **MPU의 `AD0`는 띄워 둔다.** 3.3 V에 붙으면 주소가 `0x69`로 바뀐다
· 풀업 저항은 두 모듈에 이미 실려 있다. 따로 달지 않는다
· 스위치는 `INPUT_PULLUP`이라 **GND로 당기는** 배선이다. 3V3에 붙이지 않는다

## 03이 중요한 이유

`config.h`의 `SAMPLE_HZ = 62.5f`는 **계산해서 나온 값**이다(1000÷16).
실제 칩이 그 속도로 돈다는 보장이 없다 — 자이로를 끄면 MPU는 내부 RC 발진기로 도는데
오차가 ±1% 쯤 된다.

`03_mpu_rate`는 **루프를 몇 번 돌았나가 아니라** MPU의 `DATA_RDY` 비트가 몇 번 올라왔는지를 센다.
전자는 ESP32가 스스로 정한 주기를 다시 읽는 것일 뿐이라 항상 62.5가 나온다. 측정이 아니다.

여기서 잰 값이 62.5와 1% 넘게 다르면:
1. `firmware/config.h` 의 `SAMPLE_HZ` 를 **잰 값**으로 바꾼다
2. `python3 tests/crosscheck.py` 를 다시 돌린다

대역 경계를 Hz로 두고 빈을 실행 중에 계산하므로, fs를 바꿔도 PC에서 정한 임계값은 그대로 넘어간다.
**바꾸지 않으면** 분석과 기기가 다른 주파수를 보게 된다.

## 자주 막히는 자리

| 증상 | 원인 |
|---|---|
| **Tools → Port 에 아무것도 없음** | ① **충전 전용 케이블**이다 — 데이터선이 없는 케이블이 흔하다 ② USB-시리얼 드라이버(CP2102 / CH340) 미설치. 꽂기 전후로 `ls /dev/cu.*` 를 비교하면 구분된다 |
| 업로드가 `Connecting....___` 에서 멈춤 | BOOT 버튼을 누른 채 업로드 시작, 진행되면 뗀다. USB 드라이버(CP2102 / CH340) 미설치도 흔하다 |
| 시리얼 모니터가 깨진 글자 | 속도를 **115200** 으로 맞춘다 |
| 스캔에 아무것도 안 뜸 | SDA/SCL 바뀜, GND 공통 아님, VCC 미연결. **점퍼선부터 다시 꽂는다** |
| `0x3C` 대신 `0x3D` | OLED 모듈마다 다르다. `02` 스케치의 주석 참고 |
| 가속도 값이 전부 0 | 절전 해제(`0x6B = 0`)를 빼먹었다. 가장 흔한 첫 실수 |
| magnitude가 2.0 근처 | 레인지가 ±4 g로 잡혔다. `0x1C = 0x00` 확인 |
