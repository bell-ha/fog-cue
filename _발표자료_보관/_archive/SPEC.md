11장. 각 장을 독립 SVG 파일로. 파일명 `01.svg` ~ `11.svg`, 이 디렉터리에 저장.

## 0. 절대 규칙
- 캔버스 **1600 × 900** (16:9). `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1600 900" width="1600" height="900">`
- **외부 리소스 금지**: 웹폰트 link, 외부 이미지, `<foreignObject>` 전부 금지. 파일 하나로 완결.
- 텍스트는 반드시 `<text>` 엘리먼트. path로 변환하지 말 것 (PowerPoint에서 수정 가능해야 함).
- 모든 색은 아래 토큰 값을 리터럴 hex로 직접 기입.
- 첫 줄에 `<!-- 01 표지 -->` 형태 주석으로 슬라이드 번호와 제목 표기.

## 1. 색 규율 — 이 덱의 핵심
발표 논지가 "반복되면 안 듣게 된다"이므로 **덱 자체가 습관화되면 안 됨.**

- **강조색(오커)은 본문에서 05 · 08 · 11번에만 등장.** 나머지 8장은 완전 무채색.
- 04번을 넘기는 순간 화면에 처음 색이 등장 → 클라이맥스 장치. 04번 틱에 절대 색 쓰지 말 것.
- **침묵은 칠하지 말고 비운다.** 회색 박스로 침묵 구간을 칠하면 침묵이 아니게 됨.
- **동결·낙상에 빨강 금지.** 위험은 형태와 여백으로 표현.
- 예외: 하단 진행 틱의 활성 틱 1개는 **모든 장에서** 오커. (메트로놈 모티프)

## 3. 고정 레이아웃 (전 장 동일)
```
안전 여백      좌 110 / 우 110 (우측 끝 x=1490) / 상 90 / 하 110
슬라이드 번호  x=110  y=104   mono 20  fill=ink3   내용: "01" ~ "11"
요건 라벨      우상단. x=1490 text-anchor="end" y=104  mono 18 fill=ink3
              테두리 박스: stroke=line, fill=none, rx=3, 높이 34, 좌우 padding 14
슬라이드 제목  x=110  y=232 (baseline)  display 54  fill=ink
제목 밑 괘선   x1=110 y1=272 x2=1490 y2=272  stroke=line stroke-width="1"
본문 시작      y=346
```
### 하단 진행 틱 (전 장 필수)
틱 12개. i = 0..11, `x = 110 + i*18`, 두께 2, 하단 정렬 y2=838
- 비활성: `y1=828` stroke=line
- **활성 1개**: `y1=812` stroke=accent stroke-width="3"
- 활성 인덱스 = 슬라이드 번호 - 1 (01번→i=0, 11번→i=10). 12번째 틱은 항상 비활성.

우측 하단 러닝 캡션: `x=1490 y=838 text-anchor="end"` mono 16 fill=ink3
내용: `아타카 ATTACCA`

### 02 걷다가, 발이 바닥에 붙는다  [담당 c0]  라벨 〈주제〉
**3컷 실루엣 + 지면선 하나로 관통.** 세로 구분선·박스·프레임 전부 금지.
- 지면선: x=140 → x=1180, y=620, stroke=ink, 2px. **이 선 하나가 3컷을 관통**
- 실루엣 3개: 머리(원)+몸통+팔다리를 단색 ink로. 외곽선 없음
  - 1컷 (x≈250) 정상 보행 자세
  - 2컷 (x≈580) 두 발이 나란히 멈춤, 상체 직립
  - 3컷 (x≈900) **발 위치가 2컷과 정확히 동일**, 상체만 앞으로 기울어짐
  - ※ 발이 조금이라도 움직이면 "그냥 넘어지는 사람"이 됨. 이 그림의 전부가 이것
- 발자국: 지면선 위 작은 타원. 1컷 구간은 규칙적으로 5~6개, 2컷에서 두 발 나란히, **3컷 뒤로는 없음**
- 3컷 기울기 호: 점선, stroke=line (오커 금지)
- 캡션 (지면선 아래 y≈665, mono 18, ink3): `정상 보행` / `발이 안 떨어진다` / `상체만 앞으로`
- 우측 (x 1220~1490)에 악순환 4단계를 세로로: `동결 → 낙상 → 활동량 감소 → 보행 능력 저하` 그리고 맨 아래에서 맨 위로 돌아가는 화살표
- 좌상단 본문 1줄: `머리는 가려는데 다리가 안 나간다. 문턱·좁은 통로·방향 전환에서 특히 자주 발생한다.`
- 숫자 자리표시: `국내 환자 수 [    ] · 동결 경험 비율 [    ]` (mono 18, ink3, 점선 테두리 박스)

### 03 이미 알려진 해법이 있다  [담당 c0]  라벨 〈주제 선정 이유〉

- 본문 3줄

  - `민간요법이 아니라 신경학적 음악치료(NMT)의 정식 기법이고, 임상 근거가 있다.`
  - `기저핵을 우회하는 경로로 설명된다.`  ← "우회한다" 단정형 금지
- 중앙 도해: 메트로놈 실루엣(추가 기울어진 형태) + 오른쪽으로 박자에 맞춰 규칙적으로 찍히는 발자국. **오커 금지, 전부 무채색**
