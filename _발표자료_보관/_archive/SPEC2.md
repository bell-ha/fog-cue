# 걸음박자 벨트 — 발표 SVG 규격서 v2 (전면 개정)

v1(SPEC.md)은 폐기. 이 문서가 기준입니다. 캔버스 1600×900, 파일명 `01.svg`~`11.svg`.
외부 리소스·foreignObject 금지, 텍스트는 `<text>` 유지, marker 대신 polygon — v1과 동일.

## 0. 확정 사항

- **기기명** 걸음박자 벨트 / 통칭 **걸음박자**
- **표지 제목** 걸음이 멈추면, 박자가 나옵니다
- **부제** 파킨슨 보행 동결을 감지해, 그 순간의 보폭에 맞춘 박자를 들려주는 허리 벨트
- **러닝 캡션** `걸음박자` (한글만, 9장. 01·11 제외)
- 아타카 / ATTACCA / "멈추지 말고, 이어서" — **전량 삭제.** `grep -c 아타카 *.svg` 로 확인할 것
- 영문 `STEP BEAT` 는 01번 표지에만

## 2. 색 규율

- **구조 초록 #2F6B4F** — 밝은 장 전부, 장당 3~6회. 용도 고정: 부제 / 섹션 라벨 / 표 헤더 텍스트 / 강조 단어 / 2px 구획선
- **신호 초록** — 소리·개입 전용. 05 버스트+템포, 08 개입 버스트, 11 밑줄, **전 장 활성 틱**
- **면 #E4EAE2 / #D6DFD3** — 색이 아니라 밀도 장치. 횟수 제한 없음
- **04는 구조 초록 0회 + 신호 초록 0회** (활성 틱 제외). 부제도 ink2 회색 — "아직 아무 일도 없는 상태". 04→05 인접 대비가 클라이맥스입니다
- **05 부제는 신호 초록**
- 밝은 장에서 **신호 초록은 그래픽 전용**. 본문 텍스트에 쓰지 말 것 (대비 2.92:1). 텍스트 초록이 필요하면 구조 초록(5.62:1)
- 동결·낙상에 빨강 금지

### 하단 진행 틱 (v1과 동일)
x = 110 + i*18 (i=0..11), 두께 2, y2=838. 비활성 y1=828 stroke=line / **활성 y1=812 stroke=signal stroke-width=3**
활성 인덱스 = 슬라이드번호 - 1.
러닝 캡션: x=1490 y=838 anchor=end mono 16 fill=ink3 — `걸음박자` (01·11 제외)

## 4. 밀도 장치 4개 — 전 장 적용

1. **헤더 밴드** — 위 3절. 넘길 때 리듬이 생깁니다
2. **구획 면** — 내용 블록을 `surface` 패널 위에. **테두리 없음, 그림자 없음, rx=2.** 카드+그림자 절대 금지
3. **값 위계 3단** — 제목(ink 64) → 부제(struct 26) → 본문(ink2 26) → 캡션(ink3 18)
4. **큰 유령 숫자** — 단계·항목 번호를 `line` 색 mono **96px**로 블록 우상단에. 09의 1~4, 10의 위험 번호
보조: 섹션 구분 2px struct / 행 구분 1px line

## 6. 카피 수정 — 담당별

### 01·02·03 [c0]
- 01 표지: `걸음박자 벨트` (display 96) / `걸음이 멈추면, 박자가 나옵니다` (display 44) / 부제 26 / `STEP BEAT` mono 작게 / 작성자. 헤더 밴드·요건 라벨·슬라이드 번호 없음, 진행 틱만
- 02 캡션 `상체만 앞으로` → **`상체만 앞으로 — 그대로 넘어진다`** (3컷의 결론인 낙상이 빠져 있었음)
- 02·03 자리표시 박스 `[    ]` — **박스를 삭제하세요.** 발표 때 빈 괄호가 뜨면 "안 찾아봤다"로 읽힙니다. 사용자가 숫자를 확보하면 그때 넣습니다
- 03 `기저핵을 우회하는 경로로 설명된다.` → **`박자에 발을 맞추면, 막힌 보행 명령이 기저핵을 거치지 않는 다른 경로로 나가는 것으로 설명된다.`**
- 03 인용 → **`"저는 음악과 학생입니다. 음악치료에서 쓰는 리듬 기법을 센서로 자동화하는 것 — 그래서 이 주제를 골랐습니다."`** ("이 지점"이 어디인지 없었음)

### 04·05·11 [b6]
- **레인 라벨 `자극`/`주의` → `메트로놈 소리`/`환자의 반응`** (04·05 동일하게. 두 장의 논지를 지탱하는 라벨인데 가장 모호했음)
- 04 주석 → **`20분이 지나도 메트로놈은 계속 울린다. 익숙해져서 반응이 사라졌을 뿐이다.`**
- 05 침묵 문구 → **`20분 동안 소리가 난 것은 세 번뿐이다. 나머지는 완전한 침묵이다.`** (기존 문장은 횟수와 시간이 섞여 비문)
- 05 **템포 설명 한 줄 추가** — 버스트 아래 `그때의 보폭에 맞춘 템포 (분당 박수)`. ♩=96은 비전공 청중에겐 기호일 뿐이라, 이 줄이 없으면 05의 차별점이 통째로 전달되지 않습니다
- 11 인용 → **`"치료법은 이미 있었습니다. 저는 그 리듬 자극을 언제 꺼낼지를 정해보려 합니다."`** ("그걸" 명시화)
- 05 레인에 surface 면 깔기, 04도 동일하게

### 06·07 [12]
- 06 `FI 낮음`/`FI 높음` → **`Freeze Index 낮음`/`높음`** (약어가 정의보다 먼저 나왔음)
- 06 `확장 — SR04 초음파로…` → **`확장 — 초음파 센서(SR04)로…`**
- 07 ESP32 박스 `판정 · 제어` → **`동결 판정 · 부저 제어`**
- 07 화살표 `전송` → **`기록 전송`**

### 08·09·10 [e6]
- 08 페르소나에 **이름 부여**, 치료사 대사 복원, 타임라인 시각 4개로 1:1 정렬
- 09 `100걸음에 100이 뜬다` → **`100걸음을 걸으면 100에 가깝게 센다`** (OLED는 4단계라 1단계엔 표시할 화면이 없음 — 논리 오류였음)
- 09 2단계 `템포가 따라온다` → **`보행 속도에 템포를 맞춘다`** / 4단계 `나머지를 붙인다` → **`부가 기능을 붙인다`**
- 10 네 항목 **전부 평서형 위험 진술로 통일** (현재 질문형 2 + 평서형 2가 섞여 있음)

## 7. 유지 — 직설화하면 안 되는 곳

- **08 인용 `"딸이 앱을 깔아줬는데, 시끄러워서 안 써."`** — 수사가 아니라 **증거**입니다. "기존 해법이 있는데 왜 안 쓰나"에 사람의 입으로 답하는 유일한 자리. 다만 제목으로 올리지는 않습니다
- 11 마무리 문장 — 착지점. "그걸"만 명시화
- 02 3컷 캡션 / 09 성공 기준 / 06 축·대역 라벨 — 짧게 유지. 그림 라벨은 길어지면 그림을 방해합니다
- 07 `KIT 부품을 전부 필수인 척 나열하지 않는다` — 자기고백이라 신뢰를 벌어들이는 문장
