개인맞춤형 디바이스 개발 · 32203482 이종하 · 제출 2026.09.27

> 파킨슨 환자는 걷다가 갑자기 발이 바닥에 붙습니다.
> 그 순간을 감지해 박자를 들려주는 허리 벨트입니다.

### 발표 전 확인
- **5 → 6번 전환에 모핑(Morph)** — 두 장은 축과 동결 마커 좌표가 같습니다. 모핑을 걸면 **틱 울타리가 사라지고 버스트 3개만 남습니다.** 이 덱에서 가장 강한 장면입니다
- **Pretendard · IBM Plex Mono** 설치 여부. 없으면 대체 폰트로 떠서 글자 폭이 달라집니다
- **PDF도 함께 제출** — Mac PowerPoint는 폰트 임베딩이 안 됩니다

### 아직 비어 있는 것
**국내 파킨슨 환자 수.** [심평원 opendata.hira.or.kr](https://opendata.hira.or.kr) → 국민관심질병통계 → 파킨슨병.

## 💬 예상 질문과 답

| 질문 | 답 |
|---|---|
| 보행 속도와 케이던스 차이는 | **보행 속도 = 보폭 × 케이던스.** RAS는 케이던스를 올리지 못하고 보폭을 늘려 속도를 올립니다. 같은 박자에서 더 크게 내딛는 겁니다 |
| 이미 있는 거 아닌가 | ParCuR(Sensors 2025)이 유사합니다. **4번에서 우리가 먼저 꺼냅니다.** 우리가 더하는 건 청각 자극과 케이던스 적응입니다 |
| 왜 256샘플인가 | 64 Hz에서 정확히 4초입니다. Freeze Index 원 정의와 같은 길이입니다 |
| 261 ms 가능한가 | 아닙니다. 우리 구조는 **약 2초**입니다. 7번에 그렇게 적혀 있습니다 |
| 환자 데이터는 | DAPHNet (UCI, **CC BY 4.0**). 몸통 채널만 씁니다 |
| 그 환자 만나봤나 | 페르소나는 근거가 아니라 **근거를 사람 말로 옮긴 것**입니다. 근거는 5번입니다 |
| 왜 이 주제인가 | *(구두로)* 리듬 자극은 음악치료 기법이고, 템포를 다루는 건 제 전공 영역과 겹칩니다 |

> ### ⚠️ 위 표의 두 줄은 이후 구현 과정에서 틀린 것으로 확인됐습니다 (2026-10-14)
>
> **발표 당시의 기록이므로 위 표는 고치지 않았습니다.** 다만 최종 보고서나 추가 질의응답에
> 그대로 재활용하면 틀린 답이 됩니다. 재활용할 때는 아래로 바꾸세요.
>
> | 질문 | 발표 때 준비한 답 | **맞는 답** |
> |---|---|---|
> | 261 ms 가능한가 | 약 2초입니다 | **3~4초입니다** (hold=2에서 중앙값 3.8초) |
> | 왜 256샘플인가 | Freeze Index 원 정의와 같은 길이 | **Bächlin 2010(DAPHNet 논문)이 고른 길이**입니다 |
>
> · **지연** — '약 2초'는 유지 조건(연속 2회)만 센 숫자였고, **4초짜리 창이 채워지는 시간**을
>   빼먹었습니다. 창이 동결 구간에 충분히 들어가야 FI가 넘습니다.
>   동결 시작 위상을 16번 옮겨가며 측정한 값: `hold=1 → 2.8초 / hold=2 → 3.8초 / hold=3 → 4.8초`
> · **256샘플** — Moore 2008 원 논문의 윈도우 길이는 확인하지 못했습니다.
>   '원 정의와 같다'고 말할 근거가 없으므로 Bächlin 2010에 귀속합니다.
>
> 근거와 재현 방법: `구현/docs/HARDWARE.md` 3절, `구현/analysis/freeze_index.py :: latency()`
