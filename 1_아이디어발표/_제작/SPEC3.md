# FoG-Cue 발표 SVG 규격서 v3 — CAST 스타일 기준
SPEC.md(v1) · SPEC2.md(v2) 폐기. **이 문서가 최종입니다.**
캔버스 1600×900, 파일명 `01.svg`~`11.svg`. 외부 리소스·foreignObject 금지, 텍스트는 `<text>`, marker 대신 polygon.

## 0. 기준 — 사용자 제공 레퍼런스
`TeamCAST_발표자료.pdf` (같은 폴더). 사용자 본인이 만든 공대 발표자료이고 **"단순하지만 모호하지 않은"** 기준으로 제시했습니다.
클론하지 말고 **골격만** 가져옵니다.

## 1. 팔레트 — v2에서 전면 교체
```
bg        #FFFFFF   순백 ★ 세이지/종이색 폐기
ink       #111111   제목 (거의 검정)
ink2      #444444   본문
ink3      #888888   보조 설명·캡션
line      #E0E0E0   괘선·표 구분선
panel     #F5F5F5   연회색 카드 ★ v2에서 폐기했던 것을 되살림. CAST가 실제로 씁니다
green     #00A651   ★ 선명한 초록 — eyebrow / 제목 밑줄 / 불릿 점 / 강조 수치 / 결과 문장
green-dk  #0B7A3D   진한 초록 — 다이어그램 테두리, 강조 중 강조
green-2   #5CC98C   초록 중간 명도 ★ 차트 2단계
green-3   #B8E6CC   초록 밝은 명도 ★ 차트 3단계
※ 한 hue의 명도 단계. 구간이 3개면 green-3 → green-2 → green 순으로 진해지게.
blue      #1A73E8   파랑 — 다이어그램에서 종류가 다른 블록 구분용에만
```
- **어두운 장(04·05) 폐기.** CAST는 11장 전부 흰 배경입니다. 다크 반전은 이 톤과 안 맞습니다
- 04→05 클라이맥스는 **색이 아니라 그래프 형태 변화**로 만듭니다(울타리 → 버스트 3개)

## 1-b. 폰트 — 전 장 산세리프 ★ v1·v2의 세리프(Hahmlet) 폐기
CAST는 표지 워드마크부터 본문까지 전부 산세리프입니다.
```
제목·본문  Pretendard, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif
숫자·라벨  'IBM Plex Mono', 'D2Coding', Menlo, monospace
```

## 2. 고정 레이아웃 — CAST 골격
```
eyebrow    x=110 y=104   본문폰트 22 bold  fill=green   예: "문제 정의" "개발 세부 ①"
제목       x=110 y=168   제목폰트 54 bold  fill=ink
제목 밑줄  x1=110 y1=196 x2=196 y2=196  stroke=green stroke-width=5   ★ 시그니처. 짧은 초록 밑줄
본문 시작  y=260
페이지번호 x=1490 y=838 anchor=end  mono 18  fill=#BBBBBB   예: "5 / 11"
출처 각주  x=110 y=800~840  mono 14  fill=ink3  (여러 줄 가능)
출처 위 괘선 x1=110 y1=772 x2=1490 y2=772 stroke=line
```
- **헤더 밴드(v2) 폐기.** CAST는 밴드 없이 eyebrow+제목+밑줄로 구획합니다
- **진행 틱(v1·v2) 폐기.** 페이지 번호 `N / 11`로 대체
- **요건 라벨은 eyebrow 자리에 넣습니다.** 예: eyebrow를 `주제 선정 이유`로. 별도 박스 불필요

## 3. 기본 구성 — 좌우 2단
CAST의 모든 내용 슬라이드가 이 구조입니다.
```
좌측 (x 110~760)   불릿 설명. 초록 점(r=4, fill=green) + 본문 24 + 그 아래 보조 20 ink3
우측 (x 840~1490)  실제 그래프·차트·표·사진
```
- 불릿은 `•` 문자가 아니라 **circle 엘리먼트**로 그립니다
- 각 불릿 본문 아래에 **회색 보조 한 줄**(수치·근거)을 다는 게 CAST의 핵심 리듬입니다
- 전폭이 필요한 장(01 표지, 07 부품, 09 로드맵)은 2단을 쓰지 않아도 됩니다

## 4. 카드 — 되살립니다
`panel #F5F5F5` 배경, **rx=8, 테두리 없음, 그림자 없음.** 3열 배치가 기본.
카드 안: 초록 소제목(22 bold) → 본문(20 ink2) → 회색 출처(16 ink3)
※ v2에서 "장식적"이라고 폐기했는데 CAST가 실제로 씁니다. 판단을 뒤집습니다.

## 5. 강조 방식
- **결과·핵심 수치는 초록 볼드.** CAST 예: `탄소 56.9% 절감 · 평균 지연 36.2ms · 드롭 0`
- **문제 정의 블록**: 좌측 4px 초록 세로선 + 들여쓰기 + 굵은 본문. 한 장에 하나만
- 표: 행 배경 `panel` 교대, 헤더는 ink3, 강조 열은 green

## 6. 출처 표기 — CAST 방식 채택
본문에서 `[1]` `[2]` 번호로 참조하고, **하단 각주에 번호별 전체 서지**를 답니다.
```
[1] Ge et al., Chinese Neurosurgical Journal, 2020 (메타분석 29편·5,361명)
[2] Arch Phys Med Rehabil, 2021 (메타분석 5편·209명, 근거 수준 낮음)
[3] Pallavi et al., IEEE J Transl Eng Health Med, 2025
[4] Slemenšek et al., Bioengineering, 2024 (n=9 예비연구)
[5] ParCuR, Sensors, 2025
```
mono 14, fill=ink3. 이게 "공대 자료"로 보이게 하는 가장 큰 요소입니다.

## 7. 그래프 원칙 (06 기준 + CAST)
- 실제 데이터로 그린 플롯. 축·눈금·단위 명시

- 그래프 옆/아래에 **결론 한 줄을 초록 볼드**로
